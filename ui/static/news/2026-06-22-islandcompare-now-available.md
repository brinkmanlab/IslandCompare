After an unusual downtime period, the IslandCompare application is now online again. For those previously using IslandCompare, please note that any files previously run may need to be uploaded again before they can be re-submitted to the IslandCompare pipeline. We apologize for any inconvenience. If you have any questions about using IslandCompare, or if you experience any issues, please don't hesitate to contact us at islandpick-mail@sfu.ca. Thank you all for your interest in IslandCompare.
